04 / DISCLOSUREDETAILS
Why real HTML?

Buttons, forms, disclosures and popovers retain native keyboard and accessibility behavior.

Does it require Node or React?

No. Copy a CSS file and use any HTML renderer.

Can themes nest?

Yes. Set data-cy-theme="noir" on a section to override the Grid palette inside it.

08 / Engineering principles

BUILT FOR PRODUCTION AUDITS
LOW ENTROPY

Just CSS

No browser JS, no external assets, no runtime package dependencies. Python only builds distributable files.

PLATFORM FIRST

Native controls

Real button, dialog, popover, select, details, input and progress. No faux ARIA tab or combobox implementations.

PROGRESSIVE ENHANCEMENT

Optional effects

Decorative glows and grids are isolated from core styling; reduced-motion and forced-colors are respected.
