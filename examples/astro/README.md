# Syntyr + Astro (opt-in)

Static Astro 7 page using the locally packaged @syntyr/css core stylesheet.
Astro 7 requires Node.js >=22.23.4 and npm >=9.6.5; use a compatible
runtime to build this optional example. This does not add runtime requirements
to Syntyr core.

```sh
cd examples/astro
npm install
npm run build
npm run preview
```

Generated HTML needs no Syntyr JavaScript runtime.
