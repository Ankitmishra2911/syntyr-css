For native terminal applications

CSS cannot style an actual shell process. Use terminal/palettes.json as a shared color contract in Go, Rust, Python, or your preferred CLI stack.

Use ANSI SGR colors only when output is to a color-capable TTY. Honor NO_COLOR, CLICOLOR=0 and TERM=dumb. Logs and pipes should remain plain text.
